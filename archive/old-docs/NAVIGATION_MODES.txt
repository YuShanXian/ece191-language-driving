Historical navigation modes

The earlier browser had Free and Safe modes. Free mode preferred mapped routes
but could use labeled geometric recovery after a map maneuver failed. Safe
mode retained more conservative footprint and steering rejection. Neither mode
was a traffic-safety certification, and visual/signal conditions were not bypassed.

Multi-step actions began from prior endpoints, and new commands began from the
current browser pose. Historical mode tests used fixed scene poses and isolated
navigation from model variability. Implementation was distributed among the
old execute_language_plan scripts, free_navigation_v8.py and recording server.
Those scripts are archived; the current sim is the deployed v40 app and its
interface should not be inferred from this older note.
