Historical resource handling policy

Resources were grouped by role: doPlan viewing files, nuPlan databases/maps,
model weights, reference material and experiment output. Distinct recordings
with identical filenames were kept separate. Existing inputs and old receipts
were preserved; file identities were checked before any consolidation.

This is historical context. It does not request file moves, deletions, a
background monitor, or resumed experiments. The current repository includes
code and selected small fixtures only. Consult the task's current data guide
for placement instructions rather than running historical cleanup scripts.
