# Doh: language-guided MTR selection

Input: nuPlan scene histories and vector maps, together with language from
doPlan. Pretrained MTR produces candidate trajectories. Hyungjun Doh proposes
Word2Vec embeddings on doPlan language to support scoring or selecting a
candidate in response to an instruction.

The scorer is not yet implemented or trained. Its architecture, training
objective, and evaluation remain to be defined. No performance result is
claimed here.
